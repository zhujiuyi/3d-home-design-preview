# 3D家装预览

中文 | [English](README.en.md)

在浏览器中搭建自己的户型、布置家具，再切换到 3D 查看效果或进行第一人称漫游。户型结构和装修方案可以一起保存、加载，无需通过修改代码更换户型。

项目使用原生 HTML、CSS、JavaScript、SVG 和 Three.js，没有后端，也没有构建步骤。界面支持简体中文、繁体中文和英文。

![拖拽搭建与家具布置示例](examples/拖拽搭建预览.png)

## 快速开始

### 直接打开

下载仓库后，用浏览器打开 `index.html`。保留同目录中的 `floorplan-core.js`、`floorplan-editor.js` 和 `floorplan-projects.js`，不要只复制 HTML 文件。

3D 所需的 Three.js 模块通过 jsDelivr CDN 加载，需要网络连接及支持 WebGL 的现代浏览器。

### 本地静态服务

克隆仓库：

```bash
git clone https://github.com/zhujiuyi/3d-home-design-preview.git
cd 3d-home-design-preview
```

Windows：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

macOS / Linux：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。在运行服务的终端中按 `Ctrl+C` 停止服务。

使用应用不需要 Node.js；Node.js 仅用于运行开发测试。

## 使用流程

### 1. 新建和搭建户型

通过「文件 → 新建空白户型」填写方案名称，进入「户型搭建」。也可以通过「文件 → 加载示例户型」查看自带设计。

| 工具 | 操作与效果 |
| --- | --- |
| 房间 | 在空白画布按住拖拽绘制矩形房间，四周自动生成关联围墙 |
| 墙体 | 按住拖拽绘制水平或垂直墙，设置厚度及外墙、非承重墙、承重墙、矮墙类型 |
| 平开门 / 推拉门 / 窗户 | 在墙上沿墙拖拽绘制洞口；点击墙体则按默认宽度放置 |
| 选择 / 移动 | 拖动已有元素移动；拖动蓝色手柄调整尺寸；右侧属性面板输入精确尺寸 |

尺寸单位为 **mm**，房间宽、深按墙内净尺寸计算。窄屏下点击「搭建工具」打开工具栏。

墙体吸附按实际边界计算，支持转角、T 形连接、共线延长、移动和端点调整；不同墙厚按最近墙边对齐，吸附时显示蓝色标记。网格可选 50 / 100 / 200 mm，按住 `Shift` 临时关闭网格和墙边吸附。

新绘制房间的围墙与门窗会随房间移动和缩放更新；移动房间也会带走内部家具。拖动关联围墙时，围墙沿内外方向移动，并调整对应房间边界。独立绘制的墙体可以自由移动，已关联的门窗跟随墙体移动。

选中平开门，可修改名称、宽度、开启方向、铰链端和入户门标记。全部户型修改支持撤销和重做；绘制或拖动中按 `Esc` 可取消当前操作。

### 2. 布置家具和选择材料

点击「完成搭建 · 布置家具」，从左侧家具库点击添加预设，或拖入平面图中的指定位置。

- 家具库包含 **60 个家具与家电预设**，分为卧室、客厅、餐厨、卫浴、家电、书房休闲六类。
- 家具可移动、旋转、复制、删除、调整宽深、颜色与叠放顺序；拖动时可开启「贴墙吸附」。
- 选中房间可修改名称及地面材料；提供橡木、胡桃木、地砖、大理石、防滑砖、水磨石、地毯等 8 种材料预设。
- 测量工具支持墙面吸附，按住 `Shift` 锁定水平或垂直。
- 平面图可选择 1:60 / 1:100 比例，开关尺寸、房间名、家具、网格和承重墙图层。
- 「拆改墙体」可标记拆除或恢复非承重墙，承重墙和外墙在该工具中受保护。

房间面积以 **m²** 显示，并统计套内使用面积。地面材料费用按房间面积 × 材料单价 × **1.05** 估算，其中 5% 为损耗；该统计仅针对地面材料。

### 3. 切换 3D 预览

点击「3D 场景」或按 `T`。3D 场景根据当前户型生成，墙体、门窗、房间地面和家具与 2D 方案同步。

- 鸟瞰、斜视、俯视视角，以及点击房间列表定位到房间。
- 全高墙 / 剖切墙切换，日照时间调整和夜景灯光。
- 在 3D 中选中和拖动家具，位置同步回 2D。
- 桌面漫游使用 `WASD` / 方向键和鼠标；触屏使用虚拟摇杆及拖动画面转向。
- 平开门可点击开关，漫游时也可用 `E` 操作正前方的门。
- 通过「文件 → 导出图片」保存当前 2D 或 3D 视图。

### 4. 保存完整方案并恢复

自动保存与「文件」菜单的手动操作如下：

| 操作 | 用途 |
| --- | --- |
| 自动保存 | 修改后自动记录当前完整方案，下次在同一浏览器、同一访问地址打开时恢复 |
| 保存户型与装修方案 | 在当前浏览器保存命名方案；同名保存会更新已有记录 |
| 加载已保存方案 | 选择此前命名保存的方案，恢复完整户型和装修布置 |
| 导出完整方案 JSON | 将完整方案保存成文件，用于备份或转移 |
| 导入户型与装修方案 | 从 JSON 文件恢复方案；导入前会校验数据，无效文件不会覆盖当前方案 |
| 导出图片 | 输出当前视图的 PNG 图片，用于展示方案 |

完整方案包含：方案名称、房间轮廓、墙体、门窗及关联关系、房间名称与地面材料、家具位置 / 尺寸 / 旋转 / 颜色、拆墙记录和测量线。

本地自动保存与命名保存为独立记录。浏览器、访问协议、主机名或端口变化后，本地保存不会自动共享；跨设备或更换访问地址时，使用 JSON 导出 / 导入。

JSON 不包含镜头位置、漫游状态、灯光设置或撤销历史。撤销历史最多保留 150 步，刷新后会重置。当前只支持完整 **v2 JSON**，不兼容旧版仅包含装修布置的方案文件。

可导入仓库中的 [拖拽搭建示例](examples/拖拽搭建示例.json) 查看一个包含两间房、门窗和家具的自建方案。

## 快捷键

在输入框编辑文字或数字时，快捷键不执行画布操作。

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D / 3D |
| `V` | 选择 / 移动；搭建模式中保持户型元素可编辑 |
| `M` / `X` | 测量 / 拆改墙体 |
| `Delete` / `Backspace` | 删除当前选中的家具或搭建元素 |
| 方向键 / `Shift` + 方向键 | 微调选中元素 10 mm / 100 mm |
| `R` / `Shift+R` | 家具顺时针 / 逆时针旋转 90° |
| `R`（搭建模式，选中平开门） | 翻转门的开启方向 |
| `Ctrl/⌘ + D` | 复制选中家具 |
| `Ctrl/⌘ + Z` | 撤销 |
| `Ctrl/⌘ + Shift + Z` 或 `Ctrl/⌘ + Y` | 重做 |
| `F` / `+` / `-` | 适应窗口 / 放大 / 缩小 |
| `[` / `]` | 展开或收起左侧工具库 / 右侧属性面板 |
| `Shift + F` | 全屏 |
| `Esc` | 取消绘制或拖动、取消当前操作；漫游时暂停 |
| 漫游：`WASD` / 方向键、`Shift`、`E` | 移动、快走、开关正前方的平开门 |

## 当前功能边界

- 房间绘制工具创建矩形房间，墙体绘制工具创建水平或垂直墙体。
- 仅用独立墙围成闭合区域，不会自动生成房间、地面或面积；需要用「房间」工具创建房间。
- 自带示例的房间轮廓与墙体为独立数据，编辑示例时需分别调整；自己绘制的房间自动关联围墙和门窗。
- 房间缩放会更新围墙和洞口，家具尺寸保持原值。
- 通用墙高为 2.8 m，剖切高度为 1.2 m；推拉门当前为静态显示。

## 项目结构与开发

| 路径 | 内容 |
| --- | --- |
| `index.html` | 页面、2D / 3D 渲染、家具库及初始示例数据 |
| `floorplan-core.js` | 完整方案校验、稳定 ID、几何边界和门窗开口裁切 |
| `floorplan-editor.js` | 户型拖拽搭建、墙体吸附、尺寸及属性编辑 |
| `floorplan-projects.js` | 新建、命名保存、加载及 JSON 文件操作 |
| `examples/` | 可导入的完整方案及预览图片 |
| `tests/` | 数据、保存加载、历史记录和编辑交互测试 |

2D 使用 SVG，3D 使用 Three.js r160。当前户型结构由 `state.floorplan` 管理，与家具和材料共同参与保存及撤销 / 重做。

普通用户通过界面即可更换户型。开发时可在 `index.html` 中调整初始示例 `ROOMS`、`WALLS`、`WINS`、`DOORS`、`SLIDES`，或修改材料库 `MATS`、家具库 `LIB` 和模型函数 `buildFurniture()`。

测试使用 Node.js 自带运行器，无需安装测试依赖：

```bash
node --test tests/*.test.cjs
```

覆盖完整方案往返、无效数据保护、自动保存和命名保存、撤销 / 重做、拖拽创建和调整、门窗联动，以及转角、T 形连接、不同墙厚和反向绘制吸附。
